## English

This release adds manual update checks and a new app icon based on the menu bar’s pulse theme.

- Open the **⋯** menu in the upper-right corner for **Check for Updates** and **Quit**.
- Check GitHub’s latest stable release manually. Newer versions provide release notes and an installer download; network failures and rate limits show a retryable message. Updates are installed manually.
- Version information appears at the very bottom, below the last quota query time.
- Adds a blue pulse app icon with standard and Retina sizes for Finder and the installer.
- Signed with Developer ID Application; the app and DMG are Apple-notarized, with notarization tickets stapled to both.

**Requirements:** Apple Silicon (arm64), macOS 14 or later, and a separately installed [Codex CLI](https://github.com/openai/codex#installing-and-running-codex-cli), which the app locates automatically.

**Install:** Download `Codex-Pulse-0.8.3.dmg`, open it, and drag **Codex Pulse** into **Applications**. Quit the existing app before replacing it. Existing local accounts and scheduling checkpoints are retained.
