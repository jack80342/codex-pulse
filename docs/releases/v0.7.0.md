# Codex Pulse 0.7.0

## English

Codex Pulse is a macOS menu bar app for managing multiple Codex accounts, viewing their quotas, and sending minimal model requests at server-reported reset times.

### Highlights

- Chinese and English interfaces, selected automatically from macOS preferred languages on launch. Reopen the app after changing preferred languages. Chinese variants use Simplified Chinese; other languages fall back to English when no supported language is listed.
- Real usernames, plans, remaining five-hour and weekly quotas, reset times, and automatic request status.
- In-app account management: add, log in, cancel login, reauthenticate, and remove local accounts, with no account count limit.
- Launch at login, scheduling recovery after restart or wake, and checkpoints to avoid repeated attempts within the same window.
- Separate local login data for each account. Duplicate entries share quota; only the first eligible entry sends automatic requests. Requests consume quota and stop when weekly quota is exhausted.

### Requirements and installation

- **Apple Silicon Mac (arm64), macOS 14 or later.** This DMG does not include an Intel build.
- Install [Codex CLI](https://github.com/openai/codex#installing-and-running-codex-cli) separately; Codex Pulse locates it automatically.
- Download `Codex-Pulse-0.7.0.dmg`, open it, and drag **Codex Pulse** to **Applications**. Quit an existing copy before replacing it, then launch the app and manage accounts from its menu bar icon.
- This build uses local ad-hoc signing and is **not Developer ID signed or notarized**. macOS may block the first launch and require manual approval. Updates use the existing local account data.
- Scheduling requires the app to be running, the Mac to be awake, and network access. Usernames rely on an internal read-only profile endpoint; future Codex CLI or endpoint changes may require an update.

### Validation

99 automated tests passed. Chinese and English were checked in 14 independent native-host rendering scenarios. The DMG checksum, app signature, minimum OS, architecture, and bundled language resources were verified. The package contains no account credentials or runtime account data.

## 简体中文

Codex Pulse 是 macOS 菜单栏工具，用于管理多个 Codex 账号、集中查看额度，并按服务端重置时间发送最小模型请求。

### 主要功能

- 启动时按 macOS 首选语言自动选择中文或英文；更改首选语言后重新打开应用生效。中文变体统一使用简体中文，首选语言列表没有中英文时使用英文。
- 展示真实用户名、套餐、五小时及周剩余额度、重置时间和自动请求状态。
- 应用内新增、登录、取消登录、重新登录及删除本地账号，账号数量不限。
- 支持登录时启动，重启及唤醒后恢复调度，使用检查点避免同一窗口重复尝试。
- 各账号独立保存本地登录数据；同一身份的重复条目共享额度，仅首个符合条件的条目自动请求。模型请求会消耗额度，周额度耗尽时停止。

### 要求与安装

- **Apple Silicon Mac（arm64），macOS 14 及以上。** 此 DMG 不包含 Intel 版本。
- 需单独安装 [Codex CLI](https://github.com/openai/codex#installing-and-running-codex-cli)，应用会自动查找。
- 下载 `Codex-Pulse-0.7.0.dmg`，打开后将 **Codex Pulse** 拖入 **Applications**。更新时先退出旧版再替换，启动后通过菜单栏图标管理账号。
- 当前为本地 ad-hoc 签名，**尚未完成 Developer ID 签名和公证**。macOS 可能阻止首次打开，需要手动批准。更新沿用已有本地账号数据。
- 调度需要应用运行、Mac 保持唤醒且网络可用。用户名依赖只读内部资料接口，Codex CLI 或接口升级后可能需要适配。

### 验证

99 项自动化测试通过；中英文共完成 14 个独立原生宿主界面渲染检查。DMG 校验、应用签名、最低系统版本、架构及语言资源检查通过，安装包不包含任何账号凭据或运行时账号数据。
