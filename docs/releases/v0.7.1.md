# Codex Pulse 0.7.1

## English

This release completes Developer ID signing and Apple notarization for distribution outside the Mac App Store. Account management, quota display, scheduling, and the Chinese/English interface remain as in 0.7.0.

- Signed with Developer ID Application, with Hardened Runtime and a secure Apple timestamp.
- Both the app and DMG were accepted by Apple’s notarization service. Notarization tickets are stapled to both, including the app inside the DMG.
- Includes the MIT license in the application bundle.

**Requirements:** Apple Silicon (arm64), macOS 14 or later, and a separately installed [Codex CLI](https://github.com/openai/codex#installing-and-running-codex-cli), which the app locates automatically.

**Install:** Download `Codex-Pulse-0.7.1.dmg`, open it, and drag **Codex Pulse** into **Applications**. Quit an existing copy before replacing it. Existing local account data is retained.

**Validation:** 99 automated tests passed. The final DMG and its contained app passed signature and stapled-ticket checks; the app passed Apple’s `syspolicy_check distribution` checks. Architecture, minimum OS, language resources, MIT license, and the absence of account credentials in the bundle were verified. First launch on a separate Mac with default Gatekeeper settings has not yet been verified.

## 简体中文

本版本完成面向 Mac App Store 之外分发的 Developer ID 签名和 Apple 公证。账号管理、额度展示、自动调度和中英文界面沿用 0.7.0。

- 使用 Developer ID Application 签名，启用 Hardened Runtime 和 Apple 安全时间戳。
- 应用与 DMG 均通过 Apple 公证，并附加公证凭证；DMG 内的应用也包含凭证。
- 应用资源中包含 MIT 许可证。

**要求：** Apple Silicon（arm64）、macOS 14 及以上，另需安装 [Codex CLI](https://github.com/openai/codex#installing-and-running-codex-cli)，应用会自动查找。

**安装：** 下载 `Codex-Pulse-0.7.1.dmg`，打开后将 **Codex Pulse** 拖入 **Applications**。更新时先退出旧版再替换，保留已有本地账号数据。

**验证：** 99 项自动化测试通过。最终 DMG 及其中应用的签名和附加凭证检查通过，应用通过 Apple 的 `syspolicy_check distribution` 分发检查；架构、最低系统版本、语言资源、MIT 许可证和无账号凭据打包检查通过。尚未在另一台使用默认 Gatekeeper 设置的 Mac 验证首次启动。
