# Codex Pulse

[English](README.md) | 简体中文

## 工具介绍

Codex Pulse 是一个 macOS 菜单栏工具，用于管理多个 Codex 账号、集中查看额度，并按服务端重置时间发送最小模型请求，启动新的五小时使用窗口。

- 展示真实用户名、套餐、五小时及周剩余额度和重置时间。
- 在应用内新增、登录、重新登录及删除账号，账号数量不设上限。
- 支持手动刷新、重启及唤醒后恢复调度，以及登录时启动。

支持 macOS 14 及以上，自动查找已安装的 Codex CLI。

## 原理说明

### 账号隔离与额度查询

每个账号使用独立的本地 `CODEX_HOME`，通过 Codex CLI 的 app-server 登录和查询额度。用户名来自只读内部资料接口，额度、窗口时长和重置时间以服务端返回值为准；未返回的数据显示“未知”。查询失败时保留上次成功的额度，并标记为旧数据。

### 自动请求

1. 应用启动时读取各账号额度，并检查本地保存的请求检查点。
2. 对符合条件且当前窗口尚未尝试过的账号，发送一次最小模型请求。单纯查询额度不会启动使用窗口，模型请求会消耗额度。
3. 请求完成后读取服务端返回的下一次五小时重置时间，据此安排下次检查；已有窗口保持原来的重置时间。
4. 发送前先记录本次尝试。手动刷新、重启或唤醒时沿用检查点，避免同一窗口重复尝试，也不补发错过的轮次。
5. 周额度耗尽时停止自动请求；认证或额度信息不可用时暂停；五小时额度耗尽时等待重置。同一身份的重复条目共享额度，仅首个符合条件的条目自动请求。

额度查询和自动请求各最多同时运行三个任务。账号管理期间暂停刷新和调度，操作结束后恢复。自动调度需要应用运行、Mac 处于唤醒状态且网络可用。

### 本地存储

账号凭据保存在各自独立的本地目录中，请求检查点也保存在本机，重启后可继续使用。应用通过这些独立目录管理账号，不改变日常 Codex App 的登录状态。
